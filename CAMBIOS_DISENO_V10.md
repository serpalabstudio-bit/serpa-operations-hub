# SERPA Operations Hub v1.0 — identidad visual

- Se incorpora **sin reinterpretación** el PSD facilitado, exportado a PNG RGBA transparente (`public/serpa-logo-original.png`).
- Nuevo tratamiento visual de navegación, paneles, formularios, estados hover/focus, acceso y recuperación de contraseña.
- No se han cambiado modelos de datos, migraciones SQL ni lógica de permisos.
- La web de referencia no fue accesible desde la herramienta de inspección; por tanto, es una **adaptación de estilo** y no una copia pixel-perfect verificada.
- Antes de desplegar: ejecutar `npm install` y `npm run build`, revisar el aspecto visual en móvil y escritorio.
- Actualizar archivos en el **repositorio original**; no crear otro proyecto Vercel.
